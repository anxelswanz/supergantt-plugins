# 故障树分析

把一个问题或阻碍当成**顶事件**，用与门 / 或门一层层拆到基本原因；逐个标「已确认 / 已排除」，
自动推出哪条因果链成立、还剩哪些最小割集。

## 开始

- 在事项页对一条问题或阻碍点 ⋯ →「建故障树分析」，它就成为一棵树的顶事件
- 也可以在「故障树」视图里直接新建

## 画布

- 中间事件挂**或门**（任一输入发生即导致上层）或**与门**（全部同时发生才导致）
- 拆到底的是**基本事件** ○，暂时不拆的是**未展开事件** ◇
- 键盘：选中节点后 `Tab` 加子原因、`↵` 加同级、`空格` 改名、`⌫` 删除、`⌥←→` 调顺序、`⌘Z` 撤销

## 推导

- 基本事件标「已确认 / 已排除」后按门的逻辑往上推：成立的因果链染红，被排除的分支变淡
- 已确认、拆到底、又在成立链上的事件自动打「根因」角标
- 右栏列出**最小割集**（能单独导致顶事件的最小原因组合），悬停时在画布上高亮

## 对策

节点可以是现象 / 原因 / 对策。对策用绿色虚线往下挂，记状态（待做 / 进行中 / 已完成 / 无效）
和截止日期，不参与推导。挂在顶事件下的是临时措施，挂在原因下的是根本对策。

## 其他

- 任何事件都能关联一条事项，事项页上会出现「故障树」标签
- 「复制大纲」把整棵树导出成缩进文本，贴进周报或邮件
- 树存在插件的 `data/trees.json`，按项目分开。卸载不删数据，重新安装后树都还在

## 权限

不运行任何本机程序。
