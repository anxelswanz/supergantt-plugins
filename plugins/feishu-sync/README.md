# 飞书同步

把分拣好的事项同步到飞书多维表格。后台调用 Claude，按表格的字段含义智能填写、润色中英文描述，逐条新建或更新记录。

## 准备

本机要装好并登录：

- `claude`（Claude Code）
- `lark-cli`，并 `lark-cli auth login` 授予文档搜索、多维表格读写、通讯录搜索的权限

## 用法

1. 启用后，工具条上多出「飞书」视图
2. 在事项页的分拣菜单里，把已分拣的事项「加入飞书同步」
3. 到「飞书」页选一张多维表格，勾选要同步的事项，点同步

事项改过之后会标出「有变更」，再同步一次就更新到飞书。

## 和故障树联动

在故障树里点「确认解决方案」时勾选「同步到飞书」，这条问题会自动加入同步队列并在后台同步
（需要先在「飞书」页选好目标表格）。根因、因果链、对策、解决方案、排查步骤会作为结构化信息交给 Claude，
它对照表格的字段决定拆进哪几列；表里没有对应的列就合并进最接近的那一列。

在故障树里撤回解决方案时，飞书上的记录不会被改动：队列里那一条会显示「有变更」，要不要再同步由你决定。

## 在 Claude Code 里用

启用时，插件附带的 `gantt-feishu` 技能会链接到 `~/.claude/skills/`。在任意 Claude Code 里说
「用 gantt-feishu 把飞书队列同步到 <多维表格链接>」，走的是同一份队列和填写规则。

## 权限

- 运行本机程序：`claude`、`lark-cli`、`gantt`
- 启用时链接 Skill：`gantt-feishu`
- 同步队列存在插件的 `data/queue.json`，卸载不删
