# 备件清单

按项目管一份备件台账：搜关键字、按字段筛、用一个扣一个、盘点时按实盘数校准，每次变动都留一条库存变更日志。发货单可以贴文字让 AI 识别，也可以在 Claude Code 里用 `gantt-spare-parts` 技能直接把单据录进来。

## 用法

1. 启用后，工具条上多出「备件」视图。**备件跟着项目走**：先打开一个项目，看到的就是这个项目的备件
2. **新增**：右上「＋ 新增」，填名称、SKU、规格、分类、位置、单位、初始库存
3. **搜索 / 筛选**：搜索框查名称、SKU、规格、分类、位置、备注；旁边按状态（库存不足 / 没库存 / 正常）、使用时间、分类、单位筛
4. **使用**：行上点「使用」→ 填数量、**选用在哪台设备**（没有就当场新建）、选领用人 → 扣库存，写一条使用日志。库存不够直接拦住，不会扣成负数
5. **入库**：补货、归还都点「入库」
6. **盘点**：右上「盘点」→ 只填实盘数 → 确认后库存直接改成实盘数，盘盈盘亏各写一条盘点日志。没填的行不动
7. **日志**：「日志」页按备件、设备、类型、日期筛，能导出成 Markdown / Word
8. **删除**：编辑弹窗里点「删除」—— 库存清零并记一条日志，条目进了「已删除」，在筛选条的「已删除 N」里能看到并恢复（恢复后库存是 0，要用「入库」补回来）。序号不复用
9. **飞书同步**：见下
10. **从发货单导入**：贴发货单的文字 → AI 拆成条目（单价、批次这类进自定义列）→ 导入。SKU 已有的入库，没有的新建；「导入」页能整批撤销

## 飞书同步

「飞书」页贴一个多维表格的链接，两种用法：

- **自动建两张表**：备件清单、库存变更日志（日志表的「备件」列是指向备件表的**关联记录**，点开能穿透看备件）
- **关联已有的表**：表里要有 `gantt_part_id` / `gantt_log_id` 两列（隐藏列也行），插件靠它们认出哪些行是自己写的，之后只更新不重复建

点「同步」：备件表按序号 / SKU 匹配，库存变了就更新那一行；日志表只追加。**只推不拉** —— 飞书里改了不会回写本地，也不会删你那边已有的记录。

同步是手动的，没有定时器。

## 序号

每个项目里的备件从 1 开始编号，一直往上加；归档了的号不回收，日志和飞书里都靠它认条目。

## Claude Code 里录发货单

装上插件后，技能 `gantt-spare-parts` 会出现在 Claude Code 里。把发货单图片拖进对话，说「录进 XX 项目的备件」：

- 应用没开：直接写进台账
- 应用开着：放进收件箱，备件页开着的话 5 秒内自己入库

## 设置

暂无。

## 权限

- 运行 `claude`（发货单识别）、`gantt`（命令行）、`lark-cli`（飞书同步）
- 读写自己的台账文件：`<数据目录>/plugins/spare-parts/data/accounts/<账号>/inventory-<项目 id>.json`

## 还不支持

- 飞书只推不拉：飞书里改了不会回写本地
- 项目导出 / 云备份不带备件：换电脑要另外把台账文件拷过去
